# IoT Система автоматического налива и контроля слива жидкости в резервуаре

Интеллектуальная распределённая IoT-система для удалённого мониторинга и автоматического управления уровнем воды в резервуаре с обнаружением утечек, автоматическим наполнением и облачным управлением несколькими станциями.

## Обзор

Этот проект реализует полноценное IoT-решение для автоматизированного управления резервуаром с водой:

- **Мониторинг в реальном времени** уровня воды и влажности почвы
- **Автоматическое управление насосом** с гистерезисным наполнением
- **Алгоритм обнаружения утечек** для предотвращения потери воды
- **Локальное управление** через десктопное приложение Electron на Raspberry Pi
- **Удалённый доступ** через облачный VPS с веб-интерфейсом
- **Поддержка нескольких станций** для управления множеством резервуаров с одной панели

### Ключевые возможности

| Функция | Описание |
|---------|----------|
| Мониторинг уровня | Ультразвуковой датчик HC-SR04 измеряет уровень воды с точностью ±1см |
| Измерение влажности | Ёмкостной датчик влажности почвы для обратной связи полива |
| Режим авто-наполнения | Поддерживает целевой уровень с гистерезисом ±5% для предотвращения циклирования насоса |
| Обнаружение утечек | Определяет непредвиденную потерю воды при сухой почве |
| Двойной интерфейс | Локальное Electron-приложение + удалённая веб-панель |
| Хранение данных | PostgreSQL хранит измерения за 7 дней |
| Безопасный удалённый доступ | JWT-аутентификация + HTTPS через Let's Encrypt |

### Поток данных

1. **Датчик → Arduino**: Nano считывает показания датчиков HC-SR04 (уровень) и YL-69 (влажность)
2. **Arduino → ESP8266**: Последовательная связь на скорости 9600 бод с JSON-сообщениями
3. **ESP8266 → Raspberry Pi**: WebSocket-соединение с локальным API
4. **Raspberry Pi → VPS**: WebSocket-мост для удалённого доступа
5. **VPS → Браузер**: Обновления в реальном времени через WebSocket

### Поток команд

1. **Действие пользователя** в UI (локальный Electron или удалённый веб)
2. **API получает** команду (REST или WebSocket)
3. **PumpController** проверяет и передаёт на Arduino
4. **Arduino выполняет** управление реле
5. **Обновление состояния** распространяется обратно по цепочке

## Установка и развёртывание

### Предварительные требования

- Raspberry Pi 5 с Raspberry Pi OS
- Установленные Docker и Docker Compose
- Arduino IDE для прошивки микроконтроллеров
- Node.js 18+ (для сборки Electron-приложения)
- VPS с публичным IP (для удалённого доступа)

### 1. Настройка Arduino

#### Прошивка Nano #1 (Управление насосом)

```bash
# Откройте Arduino IDE
# Файл → Открыть → arduino/nano1_pumps/nano1_pumps.ino

# Настройте учётные данные WiFi в коде ESP8266:
# - WIFI_SSID
# - WIFI_PASSWORD
# - WEBSOCKET_HOST (IP Raspberry Pi)
# - WEBSOCKET_PORT (8000)

# Выберите плату: Arduino Nano
# Выберите процессор: ATmega328P (Old Bootloader)
# Загрузите
```

#### Прошивка Nano #2 (Датчик влажности)

```bash
# Откройте Arduino IDE
# Файл → Открыть → arduino/nano2_moisture/nano2_moisture.ino

# Та же конфигурация WiFi, что и для Nano #1
# Загрузите
```

### 2. Развёртывание на Raspberry Pi

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd IoT_final_project/raspberry

# Создайте файл окружения
cp .env.example .env

# Отредактируйте конфигурацию
nano .env
```

Настройте размеры резервуара и калибровку датчика через API или UI:

```json
{
  "calibration": {
    "length": 100,          // Длина резервуара в см
    "width": 50,            // Ширина резервуара в см
    "height": 60,           // Высота резервуара в см
    "distance_empty": 65,   // Показание расстояния при пустом баке (см)
    "distance_full": 5      // Показание расстояния при полном баке (см)
  }
}
```

### Калибровка датчика влажности

Отредактируйте константы в `arduino/nano2_moisture/nano2_moisture.ino`:

```cpp
const int DRY_VALUE = 800;   // Аналоговое значение в сухом воздухе
const int WET_VALUE = 300;   // Аналоговое значение в воде
```

### Настройки авто-режима

- **Целевой уровень**: Устанавливается через UI (0-100%)
- **Гистерезис**: ±5% (зашит в `auto_mode.py`)
- **Поведение**: Насосы ВКЛ когда уровень < цель-5%, ВЫКЛ когда уровень > цель+5%

### Пороги обнаружения утечек

Отредактируйте в `raspberry/api/services/leak_detection.py`:

```python
LEAK_THRESHOLD_PCT_PER_SEC = 0.05  # Скорость падения 5%/минуту
```

## Устранение неполадок

### Arduino не подключается

1. **Проверьте учётные данные WiFi** в коде ESP8266
2. **Убедитесь в правильности IP Raspberry Pi**
3. **Проверьте последовательное соединение** между Nano и ESP8266
4. **Мониторьте последовательный вывод** на скорости 115200 бод

### Нет данных с датчиков

1. **Проверьте проводку** согласно схемам
2. **Проверьте питание датчиков** (5В для HC-SR04, 5В для YL-69)
3. **Протестируйте датчики независимо** с простыми скетчами

### Сбой WebSocket-соединения

1. **Проверьте файрвол** разрешает порт 8000
2. **Убедитесь, что Docker-контейнеры** запущены
3. **Проверьте логи API**: `docker-compose logs api`

### VPS не получает данные

1. **Проверьте VPS_WS_URL** в конфигурации Raspberry Pi
2. **Убедитесь, что API_KEY** совпадает на обеих сторонах
3. **Проверьте валидность TLS-сертификатов**
4. **Проверьте логи Traefik**: `docker-compose logs traefik`

### Проблемы с базой данных

```bash
# Сбросить базу данных
docker-compose down -v
docker-compose up -d

# Проверить логи базы данных
docker-compose logs db
```

### Насос не отвечает

1. **Проверьте проводку реле** и питание
2. **Убедитесь, что Arduino получил команду** через монитор порта
3. **Протестируйте реле вручную** прямым сигналом
4. **Проверьте напряжение блока питания** насоса
